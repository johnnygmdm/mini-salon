프로젝트 개요 (Overview)

Mini Salon CRM은 1인 헤어살롱/미용실 원장님이 매장 내 PC와 외부 스마트폰/태블릿 어디서든 동일한 고객 정보와 시술 이력을 실시간으로 관리할 수 있도록 설계된 풀스택 통합 솔루션입니다.

PC 전용 앱

파이썬 Qt(PySide6) 기반 단일 실행 파일(.exe)로 빠른 응답 속도와 키보드 친화적 작업 환경, 무중단 자동 업데이트 지원.

반응형 웹

Next.js 14 App Router 기반으로 Cloudflare Pages 글로벌 엣지에 배포되어 스마트폰으로 어디서나 즉시 조회/등록.

단일 사용자 보안

인가된 원장님 계정만 접속 가능하며, DB 트리거 레벨에서 신규 회원가입을 원천 차단하여 고객 개인정보를 안전하게 보호.

데이터베이스 설계 및 보안 (Database & Security)

1) 테이블 스키마 (ERD)

고객(`customers`)과 시술 내역(`treatments`)은 1 : N 관계로 연결되며, 고객 삭제 시 시술 내역도 함께 자동 삭제(CASCADE)됩니다.

테이블 컬럼명 타입 제약조건 & 설명
customers
고객 정보		 id UUID 기본키 (gen_random_uuid())
name VARCHAR(100) NOT NULL (고객명)
phone VARCHAR(20) UNIQUE, NOT NULL (전화번호)
gender VARCHAR(10) 남성 / 여성 / 기타
memo TEXT 특이사항, 모질/두피 상태 등 메모
created_at TIMESTAMPTZ 등록일시 (기본값 now())
treatments
시술 내역 (1:N)		 id UUID 기본키 (gen_random_uuid())
customer_id UUID 외래키 -> customers(id) ON DELETE CASCADE
treatment_date DATE NOT NULL (시술 진행 날짜)
menu VARCHAR(100) NOT NULL (커트, 펌, 염색 등)
price INTEGER NOT NULL (시술 금액, 기본값 0)
memo TEXT 약제 배합 비율, 호수 등 상세 기록

2) 1인 미용실 보안 아키텍처

단일 관리자 전용 회원가입 차단 트리거 (Signup Lock Trigger)

최초 관리자(ase3612@naver.com) 가입 완료 후, 악의적인 제3자가 Supabase 공개 Auth API를 통해 회원가입하는 것을 방지하기 위해 데이터베이스 트리거 레벨에서 신규 가입을 차단합니다. 

CREATE OR REPLACE FUNCTION public.block_new_user_signup()
RETURNS TRIGGER AS $$
BEGIN
    RAISE EXCEPTION '신규 회원가입이 비활성화된 1인 전용 시스템입니다.';
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE TRIGGER on_auth_user_signup_block
BEFORE INSERT ON auth.users
FOR EACH ROW
EXECUTE FUNCTION public.block_new_user_signup();

PC 데스크톱 앱 사양 (`/desktop`)

Windows 환경에서 원활한 업무 처리를 위해 가볍고 반응성이 뛰어난 Qt(PySide6) 프레임워크로 제작되었습니다.

실시간 디바운스 검색

고객 이름 및 전화번호 뒷자리 입력 시 300ms 디바운스 타이머를 적용하여 불필요한 네트워크 트래픽을 방지하고 부드러운 실시간 검색 경험을 제공합니다.

고객별 실시간 통계 산출

고객 클릭 시 총 방문 횟수, 총 이용 금액, 최근 방문일을 자동으로 집계하여 상단 요약 카드에 즉시 시각화합니다.

세션 자동 복원 (Auto Login)

로그인 성공 시 로컬 안전 캐시(`.session.json`)에 리프레시 토큰을 저장하여 앱 재실행 시 로그인 화면 없이 바로 메인 대시보드로 진입합니다.

DPI 고해상도 지원

4K/QHD 등 고해상도 모니터에서도 폰트와 컴포넌트가 깨지지 않도록 PassThrough 고해상도 DPI 스케일링 정책을 적용했습니다.

자동 업데이트 엔진 설계 (Auto-Updater)

PC용 단일 실행 파일(MiniSalon.exe)은 실행 중인 파일 자체를 덮어쓸 수 없는 윈도우 OS의 파일 락(Lock) 특성과 PyInstaller의 가상 임시 폴더 구조를 고려하여, PowerShell 비동기 오케스트레이션 기법으로 설계되었습니다.

sequenceDiagram autonumber participant App as MiniSalon.exe (v1.0.0) participant Server as Cloudflare Pages (version.json) participant GitHub as GitHub Releases participant Script as PowerShell Updater App->>Server: 1. 앱 기동 직후 최신 버전 질의 (HTTP GET) Server-->>App: version: 1.0.1 반환 (1.0.1 > 1.0.0 감지) App->>App: 2. 로그인 창 이전 [업데이트 알림 창] 즉시 팝업 Note over App: 사용자가 [지금 자동 업데이트] 클릭 App->>GitHub: 3. 신규 MiniSalon.exe 스트림 다운로드 (128KB Chunks) GitHub-->>App: 다운로드 완료 (MiniSalon_NewVersion.exe) App->>Script: 4. PowerShell 업데이트 스크립트 비동기 생성 및 구동 App->>App: 5. 구 프로세스 완전 종료 (os._exit(0)) Script->>Script: 6. 구 프로세스 PID 소멸 감시 (Get-Process Loop) Script->>App: 7. 새 파일로 덮어쓰기 (Copy-Item -Force) Script->>Script: 8. PyInstaller 런타임 환경변수(_PYI_*) 완전 초기화 Script->>App: 9. 깨끗한 독립 세션으로 새 버전 실행 (Start-Process) Script->>Script: 10. 임시 스크립트 및 다운로드 파일 자체 삭제

핵심 문제 해결 포인트: PyInstaller 6+ 런타임 환경변수 격리

PyInstaller 단일 파일로 묶인 앱이 자식 프로세스를 띄우면 _PYI_APPLICATION_HOME_DIR 및 _MEIPASS 환경변수가 그대로 상속됩니다. 이전 프로세스가 종료되면서 구 임시 폴더가 삭제되었는데, 새로 뜬 프로세스가 이 상속된 경로를 참조하여 LoadLibrary: 지정된 모듈을 찾을 수 없습니다 오류가 발생합니다. 본 시스템은 PowerShell에서 해당 환경변수를 $null로 명시적 초기화하여 완벽한 무결점 재기동을 보장합니다.

모바일 / 웹 클라이언트 사양 (`/web`)

Next.js 14 App Router와 Tailwind CSS로 제작되어 스마트폰, 아이패드, 매장 외부 PC 어디서나 브라우저를 통해 동일하게 접속할 수 있습니다.

완전 정적 내보내기 (SSG Export)

next.config.mjs에 output: "export"를 적용하여 Node.js 서버 비용 없이 순수 정적 파일(HTML/JS/CSS)로 빌드됩니다.

배포 프로덕션 도메인: https://mini-salon.pages.dev SSL 보안 인증서 적용됨

실행 및 빌드 방법 (How to Run & Build)

1) PC 데스크톱 앱 실행 및 패키징

개발 모드 실행 또는 단일 .exe 파일 생성:

# 1. 데스크톱 앱 개발 모드 실행
cd desktop
python main.py

# 2. PyInstaller를 통한 단일 실행 파일(.exe) 빌드
cd desktop
build_exe.bat
# -> desktop/dist/MiniSalon.exe 생성 완료

2) 웹 클라이언트 로컬 실행 및 Cloudflare 배포

# 1. 로컬 개발 서버 실행 (포트 3000)
cd web
npm run dev

# 2. 정적 빌드 및 Cloudflare Pages 프로덕션 배포
cd web
npm run build
npx wrangler pages deploy out --project-name=mini-salon --branch=master

신규 버전 배포 가이드 (Release Guide)

추후 새로운 기능을 추가하여 v1.0.2 등의 신규 버전을 배포할 때는 아래의 4단계를 진행하면 사용자의 PC 앱에서 즉시 원클릭 자동 업데이트가 제공됩니다.

  1. 1
    버전 번호 변경: desktop/services/updater_service.py의 CURRENT_VERSION = "1.0.2"로 변경합니다.
  2. 2
    신규 .exe 빌드: cd desktop && build_exe.bat를 실행하여 최신 MiniSalon.exe를 생성합니다.
  3. 3
    GitHub Release 에셋 업로드: GitHub 저장소에 새 태그(v1.0.2)로 릴리즈를 생성하고 빌드된 MiniSalon.exe를 첨부합니다.
  4. 4
    version.json 갱신 및 웹 배포: web/public/version.json 파일의 버전을 1.0.2로 업데이트하고 Cloudflare Pages로 배포합니다.
